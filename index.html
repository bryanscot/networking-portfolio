About me

~/about

I got into networking the way most people get into it honestly — by being the person who could figure out why the Wi-Fi was down. That curiosity turned into a habit of pulling apart topologies to understand how packets actually get from A to B, and it hasn't let up since.

I'm a Computer Science background developer moving deliberately into network engineering, treating each CCNA topic as something to lab out in Packet Tracer and GNS3 before I consider it learned. I like the discipline of it: a misconfigured ACL or a routing loop doesn't care how confident you are — it either works or it doesn't.

Right now that means daily study blocks, methodical notes, and building the kind of hands-on portfolio that shows I can configure, break, and troubleshoot a network — not just describe one.

Lab projects

~/labs

Six labs built in Packet Tracer / GNS3 while working through CCNA topics — each one configured, tested, and broken on purpose at least once.

LAB 01

VLAN & Inter-VLAN Routing (Router-on-a-Stick)

A three-VLAN office topology with a single router handling inter-VLAN traffic over a trunked subinterface to a Layer 2 switch.

What I learned

  • How 802.1Q trunking tags frames between switch and router
  • Configuring subinterfaces with encapsulation dot1Q
  • Why VLANs need a routing device to talk to each other at all
VLANTrunkingRouter-on-a-StickPacket Tracer
View on GitHub

LAB 02

Static vs. OSPF Routing Comparison

The same four-router topology configured twice — once with static routes, once with single-area OSPF — to compare convergence behaviour.

What I learned

  • Static routes don't reconverge when a link fails — OSPF does
  • Reading OSPF neighbor states from show ip ospf neighbor
  • Trade-offs between administrative simplicity and scalability
OSPFStatic RoutingGNS3
View on GitHub

LAB 03

NAT/PAT for Internet Access Simulation

A private LAN behind an edge router configured for PAT so multiple internal hosts share one simulated public IP for outbound access.

What I learned

  • Difference between static NAT, dynamic NAT, and PAT
  • Verifying translations with show ip nat translations
  • Why PAT is what most home and small-office routers actually run
NATPATPacket Tracer

LAB 04

Standard & Extended ACL Security Lab

Segmented network with ACLs restricting a guest VLAN from reaching internal servers while still allowing DNS and web traffic out.

What I learned

  • Wildcard mask math and why it's the inverse of a subnet mask
  • ACL placement rules — closest to source vs. closest to destination
  • Implicit deny, and how it silently breaks things if you forget it
ACLsVLAN SecurityGNS3

LAB 05

DHCP Server Configuration on a Router

IOS router configured as a DHCP server for two subnets, with excluded addresses reserved for infrastructure devices.

What I learned

  • Setting up DHCP pools, default gateways, and DNS options
  • Why excluded-address ranges matter for static devices
  • Troubleshooting clients stuck with an APIPA address
